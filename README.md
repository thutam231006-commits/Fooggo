# FoodGo Project

Đây là dự án quản lý đặt đồ ăn trực tuyến.

## 📖 Tài liệu dự án
- [Đặc tả dự án](docs/Nhom_DT_1_done.docx)

## 🚀 Cách chạy dự án
1. Clone repo về máy
2. Cài đặt dependencies: `composer install`
3. Chạy dự án: `php artisan serve`
